## 代表项目 / メインプロジェクト

### [CharaPicker / 拾卡姬](https://github.com/yomihime/CharaPicker)

一个使用 **PyQt6 + AI** 构建的桌面工具：从番剧、漫画、视频、图片、音频和文本素材中整理角色信息，并将结果沉淀为可追踪的知识库与结构化角色卡。

アニメ、漫画、動画、画像、音声、テキストなどの素材からキャラクター情報を整理し、追跡可能なナレッジベースと構造化キャラクターカードを作成する **PyQt6 + AI** デスクトップツールです。

它也是我目前最主要的个人工程项目——从桌面交互、数据模型和多媒体处理，到模型中间件、发布流程与持续重构，都在这里进行。

[查看源码 / ソースコード](https://github.com/yomihime/CharaPicker) · [下载 / ダウンロード](https://github.com/yomihime/CharaPicker/releases/latest) · [更新日志 / 変更履歴](https://github.com/yomihime/CharaPicker/blob/main/CHANGELOG.md)
